# 3D Career Model & Animations

Assets live in **`public/models/animations/`**:

| File | Purpose |
|------|---------|
| `Developer.glb` | Character model (displayed in Career tab) |
| `idle.fbx` | Idle animation (plays by default) |
| `clapping.fbx` | Clapping animation |
| `salute.fbx` | Salute animation |
| `victory.fbx` | Victory animation |

Paths are configured in `src/data/portfolio.ts` (`CAREER_MODEL_PATH`, `careerModelAnimations`).

To swap the model or animations, replace these files or update those constants.
